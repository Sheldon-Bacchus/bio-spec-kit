# Bioinformatics Release Checklist

## Intake

- [ ] Metadata schema validated
- [ ] Sample IDs are unique
- [ ] Replicates and groups are complete
- [ ] Reference and annotation versions are recorded

## QC

- [ ] QC metrics are machine-readable
- [ ] Thresholds are configured and reviewed
- [ ] Failed metrics have a documented decision

## Statistics

- [ ] Primary contrast is explicit
- [ ] Covariates and batch effects are addressed
- [ ] Model diagnostics are available
- [ ] Multiple-testing control is stated

## Reproducibility

- [ ] Input checksums recorded
- [ ] Pipeline revision recorded
- [ ] Tool and environment versions recorded
- [ ] Parameters and logs retained

## Release

- [ ] Final report generated
- [ ] All expected outputs exist
- [ ] Human release approval recorded
- [ ] No unresolved silent failures
