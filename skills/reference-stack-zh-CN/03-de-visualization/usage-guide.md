# DE 可视化使用指南（中文审阅版）

英文原件：[reference-stack/03-de-visualization/usage-guide.md](../../reference-stack/03-de-visualization/usage-guide.md)。

## 最小图集

1. 样本 PCA/MDS：检查批次、离群和 condition 是否符合设计。
2. MA 图：检查平均表达量与效应的关系。
3. 火山图：显示方向、原始/调整后显著性和预先声明的阈值。
4. 热图：仅使用清楚定义的 top/候选基因，说明变换和聚类。

每张图都应有比较名称、n、阈值、数据版本和可下载的源表；“图好看”不是验收标准。
