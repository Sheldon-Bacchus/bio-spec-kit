# 差异表达结果可视化

本文件是 [英文 Skill 原件](../../reference-stack/03-de-visualization/SKILL.md) 的中文审阅版。
范围包括 MA、火山图、热图、PCA/样本聚类和结果标注；图形负责诊断、沟通和审计，不产生
第二套 p 值。

## 关键原则

- 火山图同时表达效应方向与显著性；阈值线、比较名称、使用的 LFC 列和点数必须标出。
- MA 图检查效应是否随平均表达量变化，帮助发现低丰度噪声、测序深度或归一化问题。
- 热图必须说明输入变换、基因选择、行/列聚类距离、缩放方式和缺失值处理；不能把聚类
  颜色直接当作统计显著性。
- PCA/MDS 是样本层诊断，应显示 condition 与 batch；二维投影不等于机制证据。
- 可用收缩后的 LFC 改善火山图可读性，但 p 值和 FDR 仍来自原始模型；图标题/图注必须
  同时记录两者，不能产生“收缩后重新检验”的错觉。

## 可重复输出

保存绘图输入表、阈值、颜色映射、随机种子、软件版本、图源数据和命令。图只引用冻结的
完整 DE 表，不从手工编辑的结果复制粘贴。
