# Bioinformatics specification

Read the project constitution and any existing `.bio/` manifest, sample sheet,
reference lock, and vision documents before writing the specification.

The specification must define the biological question, estimand, study design,
inputs, outputs, QC criteria, statistical acceptance criteria, provenance
requirements, and explicit non-goals. Keep tool choices out of the scientific
requirements unless they are true constraints.

Use stable IDs for requirements and acceptance criteria. Each criterion must be
observable and map to an evidence artifact or validation command.
