# BioSpec MVP documentation

This directory documents the control-plane package boundary and its validation
contract. It does not contain generated research results or a run ledger.

- [`architecture.md`](architecture.md) defines the Spec Kit/Preset control
  plane, Bio Skill capability plane, execution plane, and deferred bridge.
- [`validation.md`](validation.md) defines the minimum structural checks and
  the claims those checks do not establish.
