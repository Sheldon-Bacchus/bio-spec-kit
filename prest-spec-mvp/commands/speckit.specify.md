## BioSpec MVP research framing

After reading the user request and the project constitution, make the
scientific framing explicit in the generated specification:

- state the biological or scientific question and the primary estimand;
- define the population, sample unit, comparison, and scope;
- distinguish observations, validation rules, interpretations, and claims;
- record the evidence boundary and what the work must not support;
- record unresolved choices as `[NEEDS CLARIFICATION: ...]` instead of silently
  selecting a threshold, contrast, reference, causal interpretation, or release
  decision;
- make each acceptance criterion observable and link it to a validation command
  or evidence path.

Do not execute an analysis, start a worker, select a dataset, or enter the
implementation lifecycle while creating the specification. Stop after the
specification and its requirements checklist are ready for human review.
